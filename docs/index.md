# Wildlife Monitoring Pipeline

End-to-end camera trap image classifier for New Zealand conservation.

**Thesis**: AIML 589 — Victoria University of Wellington  
**Supervisor**: Andrew Lensen  
**Dataset**: NZ Trail Cams (LILA Science) — 2.5M images, 97 species

## Task

Binary classification: **invasive mammals** (mouse, possum, rat, stoat, ferret, feral cat, hedgehog, weasel) vs **native birds** (kiwi, kea, tui, weka, fantail, kereru, robin, bellbird, morepork).

A false positive (bird classified as mammal) triggers a harmful conservation intervention. Recall is the primary metric.
